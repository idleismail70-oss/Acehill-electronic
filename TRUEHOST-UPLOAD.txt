TRUEHOST DEPLOYMENT — acehillonlinemarket.co.ke
================================================

This site is static HTML/CSS/JS. No Node, PHP, or database is required.

1. Domain and SSL
   - In Truehost, point acehillonlinemarket.co.ke to this hosting account.
   - cPanel → SSL/TLS Status → Issue a free Let's Encrypt certificate.
   - Wait until https://acehillonlinemarket.co.ke loads without a browser warning.

2. Upload files
   - Zip the site using acehillonlinemarket-truehost.zip (created next to this project)
     OR zip these items yourself:
       .htaccess, 404.html, index.html, products.html, product.html,
       services.html, special-orders.html, about.html, contact.html,
       robots.txt, sitemap.xml, css/, js/, data/, images/
   - Do NOT upload package.json or serve.json (not needed on Truehost).
   - cPanel → File Manager → public_html
   - Settings → Show Hidden Files (so .htaccess is visible)
   - Delete the default Truehost placeholder index page if one exists.
   - Upload the zip → Extract into public_html
   - If extract creates a subfolder, MOVE the files up so index.html
     sits directly in public_html (not public_html/ace-ill/index.html).

3. Check
   - https://acehillonlinemarket.co.ke           (home)
   - https://acehillonlinemarket.co.ke/products.html
   - https://acehillonlinemarket.co.ke/contact.html
   - Search and WhatsApp still work (products.json must be at /data/products.json)

4. After go-live
   - Google Search Console → add acehillonlinemarket.co.ke
   - Submit https://acehillonlinemarket.co.ke/sitemap.xml
   - Create a Google Business Profile for Garissa and Nairobi

5. Product photos
   - Put photos in public_html/images/products/
   - Use JPG, PNG or WebP. Keep each file under about 400KB.
   - In data/products.json set:
       "image": "images/products/your-photo.jpg"
   - Extra photos on the same product:
       "images": ["images/products/your-photo.jpg", "images/products/side.jpg"]
   - Replace both products.json and the photo files after you add stock.
   - If a photo is missing, the site shows a category picture instead.

Permissions: folders 755, files 644. That is the cPanel default.
