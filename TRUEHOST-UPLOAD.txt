TRUEHOST DEPLOYMENT — acehillonlinemarket.co.ke
================================================

This site is static HTML/CSS/JS. No Node, PHP, or database is required.

FOLDER LAYOUT (keep this shape in public_html)
---------------------------------------------
  index.html, about.html, contact.html, products.html, product.html,
  services.html, special-orders.html, 404.html
  css/   js/   data/   images/
  locations/
    index.html
    garissa/   (index, cctv, phones, iphone, laptops, phone-repair)
    nairobi/   (same)
  robots.txt, sitemap.xml, .htaccess

1. Domain and SSL
   - Point acehillonlinemarket.co.ke to this hosting account.
   - cPanel → SSL/TLS Status → free Let's Encrypt certificate.
   - Wait until https://acehillonlinemarket.co.ke loads cleanly.

2. Upload
   - Upload the folders above into public_html (Show Hidden Files for .htaccess).
   - Do NOT upload package.json, serve.json, or docs/.
   - index.html must sit directly in public_html.

3. Check
   - https://acehillonlinemarket.co.ke/
   - https://acehillonlinemarket.co.ke/products.html
   - https://acehillonlinemarket.co.ke/locations/garissa/cctv.html
   - https://acehillonlinemarket.co.ke/locations/nairobi/phone-repair.html

4. Google ranking (required — tags alone are not enough)
   A. Search Console → add property → submit sitemap.xml
      Request indexing for locations/garissa/ and key topic pages.
   B. Google Business Profile for Garissa and Nairobi (main local ranking).
   C. Categories: Electronics store + phone repair / CCTV where offered.
   D. Website link: https://acehillonlinemarket.co.ke
   E. Photos + customer reviews.

5. Product photos
   - Upload to public_html/images/products/
   - In data/products.json set "image": "images/products/your-photo.jpg"

Permissions: folders 755, files 644.
